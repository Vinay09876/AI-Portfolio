# AI Portfolio Chat

A personal portfolio site with a RAG-style AI chat assistant — visitors can ask questions about my background, experience, projects, and skills, and get answers grounded in real data from a Supabase database, generated by Google's Gemini API.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Database:** Supabase (Postgres)
- **AI:** Google Gemini (`@google/genai`)
- **Styling:** Tailwind CSS v4

## Features

- AI chat assistant grounded in real portfolio data (profile, experience, projects, skills, education)
- Per-visitor chat history (anonymous, browser-scoped) with rename, delete, edit-and-regenerate
- Projects, Experience, About, Contact, and Feedback pages, all backed by the database
- Dark mode
- Contact and feedback forms that write to Supabase
